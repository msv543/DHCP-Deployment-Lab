# DHCP Deployment Lab

## Overview

This lab demonstrates the deployment, configuration, and verification of a Windows Server DHCP service inside an Active Directory domain.

## Objectives

- Deploy DHCP Server role on DC1
- Create and configure an IPv4 DHCP scope
- Configure DHCP options (Router, DNS, Domain Name)
- Authorize DHCP in Active Directory
- Test lease assignment from a domain‑joined client
- Verify DHCP functionality using PowerShell + GUI tools

## Environment

- Hypervisor: VMware Workstation
- Domain: martinlab.local
- Server OS: Windows Server 2025
- Client OS: Windows 11
- VMs Used:
  - DC1 - AD DS + DNS
  - DC1 - DHCP Server
  - PC1 - Domain-joined workstation

## Prerequisites

- Domain controller installed and functioning
- DNS configured on DC1
- SRV01 joined to the domain
- Static IP assigned to SRV01
- VMware network configured NAT
- RSAT tools available
